# Сбеги с клавиатуры! — хостинг на GitHub Pages

Репозиторий отдаёт игру по HTTPS-адресу, который вписывается в настройки
мини-приложения ВКонтакте (оно же показывается в Одноклассниках).

```
public/index.html          сама игра, один файл
public/vendor/three.min.js движок
.github/workflows/deploy.yml  выкладка при пуше в main
```

## Первый запуск

1. Создайте репозиторий (например `escape-keyboard`) и залейте в него
   содержимое этой папки.
2. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
   Ветку выбирать не нужно — выкладкой занимается workflow.
3. Пуш в `main` запускает деплой. Во вкладке **Actions** видно, как он
   идёт; адрес появится там же и в Settings → Pages.

Адрес будет такой:

```
https://<ваш-логин>.github.io/<имя-репозитория>/
```

Его и вписывайте во ВКонтакте — один и тот же для веб-версии, мобильного
сайта и мобильных клиентов.

## Обновление игры

Положите новый `index.html` в `public/`, закоммитьте, запушьте. Через
минуту-полторы новая версия в эфире. Движок в `vendor/` трогать не надо.

Если деплой нужно запустить без изменений в файлах — вкладка Actions,
workflow «Deploy to GitHub Pages», кнопка **Run workflow**.

## Перед первой публикацией

В конце `public/index.html` стоит блок загрузчика GamePush с
демонстрационным `projectId=31688` из документации. Замените его своим
блоком из «Публичной зоны» проекта, иначе статистика, сохранения и
реклама уйдут в чужой проект.

## Почему папка `public`, а не корень

В артефакт попадает только она, поэтому `.github`, README и всё
служебное не раздаётся вместе с игрой.

## Пределы

Репозиторий до 1 ГБ, около 100 ГБ трафика в месяц. Игра весит ~870 КБ, а
Pages отдаёт текстовые файлы сжатыми — около 210 КБ на первый заход,
дальше из кэша браузера. Это сотни тысяч запусков в месяц.

## Если понадобится свой домен

Settings → Pages → Custom domain. Для поддомена — CNAME-запись на
`<ваш-логин>.github.io`, для корня домена — четыре A-записи на
185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153.
Затем галочка Enforce HTTPS. Файлы останутся здесь, поменяется только
адрес — и его нужно будет обновить в настройках приложения ВКонтакте.
